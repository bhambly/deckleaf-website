SUPPORT

Help when you need it.

Deckleaf works as a local notebook on its own. Anki troubleshooting applies only when you choose to connect an Anki collection.

Quick Capture does not appear

Keep Deckleaf running in the menu bar, then press Command–Shift–K. If another app already uses that shortcut, change or disable the conflicting macOS or app shortcut. Quick Capture uses the display containing your pointer and can appear over a full-screen Space.

Deckleaf cannot connect to Anki

  1. Open Anki Desktop.
  2. Install and enable AnkiConnect add-on code 2055492159.
  3. Restart Anki.
  4. Keep AnkiConnect at its default local address, 127.0.0.1:8765.
  5. Return to Deckleaf and choose refresh.

Your local Deckleaf notes remain available while Anki is closed.

Large collection is slow

Open Settings, select the decks you use in Deckleaf, and enable focused indexing. Incremental refreshes load only changed content after the first index. Search and result paging run against the local SQLite index.

An image is missing

For Anki notes, keep Anki open so Deckleaf can request media through AnkiConnect. Local Deckleaf image attachments remain available without Anki. Supported formats are PNG, JPEG, GIF, and WebP.

Reset safely

Settings → Clear cache removes only indexed Anki note content. It keeps local Deckleaf notes, local images, organization, reminders, checklists, and preferences. It never changes Anki.

Contact Deckleaf Support

Email deckleaf.admin@gmail.com. Include your macOS version, Deckleaf version, whether Anki was open, and the exact message shown. Please do not include private card content. We aim to acknowledge support requests within two business days.
