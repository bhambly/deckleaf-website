GETTING STARTED

Useful from first launch.

Deckleaf opens with a small sample library so you can try local notes, boards, reminders, checklists, search, and Quick Capture before connecting anything.

01

Open your local library

Create and organize notes on your Mac with no login, cloud account, or separate software.

See release status ↓
02

Connect Anki if you use it

In Anki, choose Tools → Add-ons → Get Add-ons. Enter code 2055492159, install it, then restart Anki.

View AnkiConnect ↗
03

Keep control

Deckleaf connects only to 127.0.0.1:8765. Local notes remain separate unless you deliberately choose Send to Anki.
